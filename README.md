# 📸 Photography Sidebar Menu

A modern and responsive photography landing page featuring a stylish glassmorphism sidebar navigation. This project focuses on creating an elegant UI using only **HTML** and **CSS**, making it a great practice project for mastering layouts, positioning, transitions, and hover effects.

---

## ✨ Features

- 📂 Responsive Sidebar Navigation
- 🎨 Glassmorphism UI Design
- 🖼️ Full-Screen Background Image
- 📱 Clean & Minimal Layout
- 🎯 Smooth Hover Effects
- 🔗 Social Media Icons
- ❌ Toggle Close Button
- 💻 Beginner-Friendly Code Structure

---

## 🛠️ Built With

- HTML5
- CSS3
- Font Awesome
